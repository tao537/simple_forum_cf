## 一、这是什么

| 项 | 值 |
|---|---|
| 代码项目 | `simple_forum_cf/`（本目录下唯一的代码项目；另一个文件 `注意` 是历史日记） |
| git 仓库根 | **`simple_forum_cf/.git`** ← 注意：**本目录（工作目录）不是 git 仓库根** |
| 站点 | 双站点：**苦海论坛** + **娱乐游戏**（游戏/galgame 分享），共用后端、数据隔离 |
| 技术栈 | Cloudflare Workers + Hono ｜ D1×2（SQLite）｜ KV（图片二进制）｜ Pages（前端静态） |
| 域名 | 前端 `https://kuhai.de5.net`（含 www）　后端 `https://api.kuhai.de5.net` |
| 模型/成本 | 本项目对 token 成本敏感，**优先用 grep/定点 read，避免整文件通读** |

架构：

```
浏览器 → Pages(frontend/ 静态)  ──fetch──→  Worker(backend/src/index.ts)
                                              ├─ D1  DB      = forum-db   论坛数据
                                              ├─ D1  GAME_DB = game-db    游戏站数据（与论坛完全隔离）
                                              └─ KV  IMG_KV  图片，绑定名 IMG_KV，key = img:<id>
```

**两套账号体系互相独立**：论坛 JWT（`/api/auth/*`，header 里 userId），游戏站先是门禁密码
（`/api/game/enter`，签发 `scope=game` token），再在其上做游戏站自己的注册/登录（`/api/game/login`）。

## 三、后端 `backend/src/index.ts` 锚点

```
19   const app = new Hono<{Bindings; Variables}>()
21   app.use('*', cors({ origin: [三个 kuhai.de5.net 域名], allowMethods: [...含 PATCH] }))
29   const IMG_RE = /^(\/img\/|https:\/\/api\.kuhai\.de5.net\/img\/)[A-Za-z0-9._-]{1,120}$/
31   sanitizeImages(input)   // 过滤 IMG_RE + slice(0,9)
219  /api/auth/register|login 与 /api/users/register|login（别名）
231  /api/posts ...           // 论坛帖 CRUD、like、pin、feature、comments
320  POST /api/posts/upload   // 存 KV：key=img:<id>，id=`${Date.now()}-${rand36}`
346  GET  /img/:id            // 读 KV，Cache-Control 1 年
1102 /api/game/*             // 游戏站：enter(门禁)、register/login、posts、comments
1552 /api/admin/*            // 分类、站点文案、游戏站统计、导出、封禁
1869 export default app
```

约定：
- 回复统一 `c.json(...)`；错误带中文 message（前端直接 `toast(e.message)`）。
- 分页 `page/size`，`size` 上限 100。
- 时间存 `TEXT`，用 `datetime('now','localtime')`。
- **改动后端必须 `npx wrangler deploy --minify` 才生效**（或 `npm run dev` 本地 8787）。

## 四、前端

- 全部是**无构建的静态 HTML + 原生 ES module**，共享 `common.js`（`import { ... } from './common.js'`）。
- `common.js` 关键导出：`API_BASE`(L28) `escapeHtml`(L70) `parseImages`(L75) `auth` `gameAuth`(L92)
  `api` `gameApi` `renderMentions`(L237) **`renderMarkdown`(L325)** `renderNav` `initMusicPlayer`(L463)。
- `API_BASE` 顶部有 `USE_LOCAL_API` 开关：本地调试时前端可指向 `http://localhost:8787`。
- 帖子正文渲染点：`post.html:402`（论坛，`{mentions:true}`）、`game-post.html:460`（游戏站）。
- **正文是 Markdown**（AI 生成的有 `## 小节`、`- 列表`、`![](图)`），由 `renderMarkdown()` 渲染。
  图片只放行与后端 `IMG_RE` 同一套白名单的 URL；手动发帖的图走顶部 `.gallery` 兜底。
- 部署：Pages 从 git 构建，**Build output directory = `frontend`**。所以**只有 `frontend/` 的改动影响线上**，
  `automation/`、`backend/` 改了不会自动上线。push 到 main 会触发 Pages 自动部署（约 30–60 秒）。

## 五、automation（本地脚本，零 npm 依赖，Node 18+）

```
fetch.mjs   → candidates/<source>-<date>.json     （候选：id/name/desc/url/cover/tags/links/images）
review.mjs  → reports/<source>-<date>.{html,md}   （人工复核用；--local-covers 下载封面防防盗链）
publish-game.mjs ← queue/*.json                   （清单：name/panUrl/panCode/genre/platform/tags/notes/screenshots）
             → ollama 生成文案 → 可选云端润色 → 截图传 KV → 发帖 → 归档 published/
```

要点：
- `queue/*.json` 里 **`screenshots` 是封面的唯一来源**；候选里的 `cover` 只给复核报告看，**不会自动进帖子**。
- `screenshots` 每项可以是**本地路径（相对清单文件）或 http(s) URL**（URL 会先直连 10s、失败走代理 30s）。
- **缺 `panCode` 不中止**：链接照发，但正文会插入一段「提取码暂缺」说明（`config.json` 的 `noCodeNotice` 可覆盖，
  空串则不插），同时在 `queue/_no-code-warnings.json` 留档。填「无需/不需要」视为本来就不需要码。
- `--dry-run` 全程无副作用（不登录/不发帖/不写文件），`--file <路径>` 只跑一条，清单名以 `_` 开头会被跳过。
- 运行前 **ollama 必须开着**（`http://localhost:11434`，当前模型 `qwen2.5:7b`）。

## 六、约定与坑（踩过的，别再踩）

1. **XSS**：正文一律**先 `escapeHtml` 再还原白名单语法**（`renderMarkdown` 内部如此）。
   **绝不** `innerHTML = 用户内容`——历史上修过存储型 XSS。图片 URL 必须过 `IMG_RE` 白名单。
2. **D1 是 SQLite**：`INTEGER PRIMARY KEY AUTOINCREMENT`、日期用 TEXT、没有 `ENUM/JSON` 类型。
   增量迁移写在 `migrate.sql` 风格里，且**尽量幂等**（游戏站账号那支明确非幂等，执行前先查列）。
3. **Workers 没有 fs/process**；密码哈希走 `nodejs_compat`。
4. **图片存 KV 不存 R2**（免绑卡）：上传返回**绝对地址**，因为前端在 Pages 上，相对路径会 404。
5. **Pages 会把 `.html` 308 跳到无扩展名**（`/post.html` → `/post`）。curl 验证加 `-L`。
6. **密钥全在 gitignore 里**：`backend/.dev.vars`、`automation/config.json`、`automation/.env`。
   读取时**不要把值打印出来**。
7. CORS 只放行三个 `kuhai.de5.net` 域名；加新方法要同步改 L21。
8. 工作目录不是 git 根，`git` 命令要 `cd simple_forum_cf`。
9. **禁止软链接**：项目内一律用**真实文件**，不要 `ln -s`。需要两处共享同一内容时，
   复制文件并在两边都注明「另一份在哪、改动要同步」。

## 九、新增抓取站点（最省 token 的流程）

### 9.1 机制（**不用注册**）

`automation/sources/galgame/` 是**扫目录**发现子站点的：新建 `sources/galgame/<slug>/index.mjs`，
导出 `export async function fetchGames(options) {...}`，就会被 `cd automation && node fetch.mjs galgame` 调到。
同目录的 `index.mjs / README.md / sites.txt.example` 等文件会被自动排除，不会误当站点。

- 参考实现**只读** `sources/galgame/youxiniao/`（index.mjs 349 行 + README 111 行，最新一份）。
- `siteA/` 与 `youxihiao/` 是它的**逐字节复制品**（10562 / 3873 字节完全一致），**不要读**。

### 9.2 单站点试跑（`fetch.mjs` **没有** `--site` 参数）

```bash
cd simple_forum_cf/automation
node -e "import('./sources/galgame/<slug>/index.mjs').then(m=>m.fetchGames({limit:3}))"
```

不要为了试一个站而跑 `node fetch.mjs galgame`（会聚合全部子站，既慢又费抓取配额）。

### 9.3 开工前先把素材喂进来（省 token 的关键）

让 agent 自己联网猜选择器是最贵的操作。请自己先在浏览器 `Ctrl+S`，或
`curl -s <url> -o <file>`，存两份**原始 HTML**：

```
automation/_samples/<slug>/list.html     列表页
automation/_samples/<slug>/detail.html   一个详情页
```

> `_samples/` 要进 `.gitignore`：大 HTML 不进 git，也不污染上线产物（只有 `frontend/` 影响线上）。

### 9.5 硬约束

- ❌ **别让 agent「先看看这个站怎么抓」**——curl → 发现 JS 渲染 → 试接口 → 试 UA → 试代理，
  一套下来轻松几万 token，而这本可以用两份本地 HTML 换掉。
- ❌ 一次只加一个站点（多站交叉调试出错难回滚）。
- ✅ automation 是**零 npm 依赖、Node 18+**，只用 `node:fs` / `node:path` / 内置 `fetch` + 项目已有工具函数。
- ✅ 需要人工复核页面样式时，跑 `review.mjs` 生成报告，而不是读脚本源码。
