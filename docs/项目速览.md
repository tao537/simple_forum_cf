## 一、这是什么

| 项 | 值 |
|---|---|
| 代码项目 | `simple_forum_cf/`（本目录下唯一的代码项目；另一个文件 `注意` 是历史日记） |
| git 仓库根 | **`simple_forum_cf/.git`** ← 本目录（工作目录）**不是** git 仓库根 |
| 站点 | 双站点：**苦海论坛** + **娱乐游戏**（galgame 分享），共用后端、数据隔离 |
| 技术栈 | Cloudflare Workers + Hono ｜ D1×2（SQLite）｜ KV（图片）｜ Pages（前端静态） |
| 域名 | 前端 `https://kuhai.de5.net`　后端 `https://api.kuhai.de5.net` |
| 成本 | 对 token 敏感，**优先 grep/定点 read，避免整文件通读** |

```
浏览器 → Pages(frontend/ 静态) ──fetch──→ Worker(backend/src/index.ts)
                                            ├─ D1  DB      = forum-db
                                            ├─ D1  GAME_DB = game-db（与论坛完全隔离）
                                            └─ KV  IMG_KV  key = img:<id>
```

**两套账号互相独立**：论坛 JWT（`/api/auth/*`）；游戏站先门禁密码（`/api/game/enter`，
签发 `scope=game` token），再做自己的注册/登录（`/api/game/login`）。

## 四、前端

- 无构建的静态 HTML + 原生 ES module，共享 `common.js`。
- 板块自带模块（都零依赖、不引第三方 CDN）：`spotify.js`（Spotify 链接解析 + 内嵌）、

  **只有 `frontend/` 的改动影响线上**；push 到 main 后约 30–60 秒自动发布。

## 五、automation（本地脚本，零 npm 依赖，Node 18+）

```
fetch.mjs   → candidates/<source>-<date>.json
review.mjs  → reports/<source>-<date>.{html,md}
publish-game.mjs ← queue/*.json → ollama 文案 → 传图 → 发帖 → 归档 published/
```

- `screenshots` 是封面**唯一来源**（本地路径或 http(s) URL）。
- 缺 `panCode` 不中止：正文插入「提取码暂缺」说明，并记进 `queue/_no-code-warnings.json`。
- `--dry-run` 无副作用；`--file <路径>` 只跑一条；清单名以 `_` 开头会被跳过。
- `--draft` 先生成 `drafts/<名>.md`（front-matter `title:` + 正文），正式发布优先用它、不再调 ollama。
- 运行前 **ollama 必须开着**（`http://localhost:11434`，当前模型 `qwen2.5:7b`）；有草稿的清单不需要。

## 六、约定与坑（踩过的，别再踩）

1. **XSS**：正文一律先 `escapeHtml` 再还原白名单语法（`renderMarkdown` 内部如此）。
   **绝不** `innerHTML = 用户内容`——修过存储型 XSS。图片 URL 必须过 `IMG_RE`。
2. **D1 是 SQLite**：`INTEGER PRIMARY KEY AUTOINCREMENT`、日期 TEXT、无 `ENUM/JSON`。
   迁移尽量幂等；游戏站账号那支**非幂等**，执行前先查列。
3. **Workers 没有 fs/process**；密码哈希走 `nodejs_compat`。
4. **图片存 KV 不存 R2**：上传返回**绝对地址**（前端在 Pages，相对路径会 404）。
5. **Pages 把 `.html` 308 跳到无扩展名**（`/post.html` → `/post`），curl 验证加 `-L`。
6. **密钥全在 gitignore**：`backend/.dev.vars`、`automation/config.json`、`automation/.env`。
   读取时**不要打印值**。
7. **CORS 只放行三个 `kuhai.de5.net` 域名**；加新方法要同步改 L21。
8. 工作目录不是 git 根，`git` 命令要 `cd simple_forum_cf`。
9. **禁止软链接**：项目内一律真实文件；两边共享内容就复制并注明。
10. **国内手机无代理只认自己域名**：`kuhai.de5.net` / `api.kuhai.de5.net` 可直连；
    `*.workers.dev`、`cdn.jsdelivr.net` 等**手机上没有代理就是超时**，前端禁止直连。
    第三方库放 `frontend/vendor/` 按需加载。改完 `common.js` 必须把所有 HTML 的
    `?v=` 版本号加一（Pages 忽略静态 JS 的 Cache-Control，版本号才是保险）。
11. **小说书源 = 中文维基文库**：`/api/novel/*` 走 `zh.wikisource.org` MediaWiki API，
    Worker 抓 + KV 缓存 1 天。只收公版/自由许可作品。注意 `query.pages` 是**对象**不是数组。
12. **音乐播放器联动**：`music.html` 与 `common.js` 右下角小播放器共用 `music_now`
    （带 `src: big|fab` 防回环）。歌单已升级成多歌单：`localStorage.music_playlists_v2`，
    旧 key `music_playlist` 首进自动迁移成「我的收藏」。网易云解析走 `music-api.gdstudio.xyz`。
13. **推代码前一律先 `git pull --rebase`，禁止 `git push --force`。**
    这个仓库有不止一处入口在推（别的机器 / 别的 AI 工具），force 会**静默抹掉别人的提交**。
    2026-11-07 实际发生过：远端被 force 后，`docs/项目速览.md` 里新增的段落直接消失。
    冲突就解决冲突，不许用 force「跳过」。
