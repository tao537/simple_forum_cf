## 5. 数据契约

### 5.1 `queue/*.json` 清单（发布脚本的输入）

```jsonc
{
  "name": "游戏名",                     // 必填（校验失败会中止）
  "panUrl": "https://...",              // 必填（网盘/商店链接，写进正文「下载信息」）
  "panCode": "无",                      // 可选：提取码
  "genre": "休闲游戏",                   // 可选
  "platform": "PC",                     // 可选
  "tags": ["单机", "回合制"],            // 可选，数组
  "notes": "无",                        // 可选，给模型的补充信息
  "screenshots": [ /* 本地相对路径 或 http(s):// URL，最多 5 张 */ ]
}
```

* `screenshots` 每一项：**本地路径**（相对该清单文件目录）或 **`http(s)` URL**。
* **关键行为差异**（别踩）：本地文件不存在 → **本条直接中止**；
  远程 URL 下载失败 → **只跳过这一张，继续发**。
* 超过 5 张 → 只取前 5，并打印提示。

### 5.2 `published/*.json` 归档（发布脚本的输出）

= 原 `queue/` 清单**原样追加三个字段**后**移动**到 `published/`（不是复制）：

```jsonc
{ /* …原字段… */ ,
  "publishedAt": "2026-10-04T05:38:46.684Z",
  "postId": 10,
  "postUrl": "https://kuhai.de5.net/game-post.html?id=10"
}
```

> 注意：归档会**重新序列化整个 JSON**（`JSON.stringify(…, 2)`），所以手写清单里
> 单行数组（如 `"tags": ["单机", "回合制"]`）在归档文件里会变成多行——
> 信息无损，是既有行为，不是 bug。

### 5.3 `candidates/*.json`（抓取产物，回填的输入）

## 6. 关键实现与坑（照抄结论，别重新踩）

1. **远程截图链路**（`publish-game.mjs`，本次新增）
   `screenshots` 项若匹配 `^https?://` → **先直连下载**（`DIRECT_TIMEOUT_MS = 10000`），
   失败才 **spawnSync 子进程走代理**（`PROXY_TIMEOUT_MS = 30000`）；
   下载结果按 URL 哈希缓存到 `/tmp/publish-game-cache/<hash>.download`。
   单张失败只 `console.log` 跳过，不中止本条。

2. **代理必须在「进程启动前」注入**（本项目最大的坑）
   Node **只在进程启动时**读 `NODE_USE_ENV_PROXY`（v26.8.2 实测），**进程内
   `process.env` 赋值无效**。所以：
   * `publish-game.mjs` 用 `spawnSync(process.execPath, ['--input-type=module','-e',SRC,…])`
     + `env: { NODE_USE_ENV_PROXY:'1', HTTP(S)_PROXY, NO_PROXY:'localhost,127.0.0.1,::1' }`；
   * `run-with-proxy.sh` 是同一路数（启动前 `export`）→ 有效；
   * `fetch.mjs` 的 `applyProxy()` 是**进程内注入 → 静默失效**（日志说走代理，实际直连），
     已记为 `项目报告.txt` 已知问题第 7 条，**本轮刻意没改**（要改走子进程/ProxyAgent 方案，
     属于独立任务）。

3. **上传接口只接受 multipart，且 `file.type` 必须是 `image/*`**
   `POST /api/posts/upload` 不支持 URL 直传 → URL 必须先下载成字节。
   若 `Blob` 不给 MIME，后端返回 400「只能上传图片」（2026-10-04 实测）。
   本地文件与下载字节都靠 **魔数嗅探**（`sniffImage`：JPEG/PNG/WebP/GIF）定 MIME，
   不要用扩展名判断。单张上限 `MAX_IMAGE_BYTES = 5MB`。

4. **每条清单最多 5 张截图**（`MAX_SHOTS`，`backfill-covers.mjs` 的 `MAX_SHOTS` 也取 5，
   两处必须保持一致，改一处就要改另一处）。

5. **发帖三步顺序不能乱**：`/api/auth/login`（论坛管理员）→ `/api/game/enter`（门禁换 token）
   → `/api/game/login`（游戏站管理员）→ 上传图 → `POST /api/game/posts`。
   正文里图片以 `## 🖼 游戏截图` + `![](论坛图地址)` 追加在末尾，把 `images` 数组一并提交。

6. **`node publish-game.mjs` 会跳过 `_` 开头的清单文件**；用 `--file` 显式指定时不跳过
   （所以能拿 `_example-game.json` 做体检）。

7. **归档 = 移动 + 追加字段**（见 5.2）。文件名里可能含**全角冒号/空格**
   （如 `Demon Lord： Clicker.json`）→ shell 里务必加引号，或干脆用 `--file` 传路径。

8. **`backfill-covers.mjs` 的四条判定规则**（幂等，可反复跑）
   ① `screenshots` 空 → 回填；② 非空但**全部**是不存在的本地文件 → 回填；
   ③ 只要有一条 URL 或一个真实存在的本地文件 → **不动**（视为用户有意配置）；
   ④ 按 `name` 在 `candidates/steam-*.json` 里精确匹配不到 → 原样保留并报告。
   回填口径：候选 `cover` 进 `[0]`，候选 `screenshots`（若有）去重后追加，总数 ≤ 5；
   写盘只替换 `"screenshots"` 文本段并用 JSON 全量比对校验（保排版），失败则还原。
   已知噪音：同名候选（10-03 与 10-04 两份候选）会打警告，属预期，勿「顺手静音」。

9. **模型调用顺序**：默认走本地 ollama 生成文案（~60 s/条，`--dry-run` 也会调）；
   只有 `cloudAi.apiKey` 非空时才调云端润色。**所以跑任何发布相关命令前先确认 ollama 在跑**，
   否则会卡在「本地模型生成文案…」很久或超时。

## 10. 只读验证脚本（贴到 `/tmp/` 跑，不入库）

用途：不发帖、不改文件，确认「服务器上这些帖子真的在、图真的能打开」。
复制成 `/tmp/verify-published.mjs` 后 `node /tmp/verify-published.mjs`。

```js
// 只读终验：遍历 published/，逐条读服务端帖子 + 真下线上图（不打印密码/token）
import { readFileSync, readdirSync } from 'node:fs';
const DIR = '/home/zhong/Desktop/project/simple_forum_cf/automation';
const c = JSON.parse(readFileSync(`${DIR}/config.json`, 'utf8'));

const g = await fetch(`${c.apiBase}/api/game/enter`, {
  method: 'POST', headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ password: c.game.gatePassword }),
});
const gd = await g.json().catch(() => null);
console.log(`门禁 HTTP ${g.status}  token ${gd?.token ? `已签发（长度 ${String(gd.token).length}）` : '无'}`);
if (g.status !== 200 || !gd?.token) process.exit(1);
const auth = { Authorization: `Bearer ${gd.token}` };

for (const f of readdirSync(`${DIR}/published`).filter((x) => x.endsWith('.json')).sort()) {
  const list = JSON.parse(readFileSync(`${DIR}/published/${f}`, 'utf8'));
  const r = await fetch(`${c.apiBase}/api/game/posts/${list.postId}`, { headers: auth });
  const p = (await r.json().catch(() => null))?.post ?? null;
  if (!p) { console.log(`❌ ${f}  postId=${list.postId}  HTTP ${r.status}`); continue; }
  let imgs = p.images; if (typeof imgs === 'string') { try { imgs = JSON.parse(imgs); } catch { imgs = []; } }
  imgs = Array.isArray(imgs) ? imgs : [];
  const live = [];
  for (const u of imgs) {
    const ir = await fetch(u, { signal: AbortSignal.timeout(20000) });
    live.push(`${ir.status}/${(await ir.arrayBuffer()).byteLength}B`);
  }
  const ok = imgs.length === String(p.content ?? '').split('🖼').length - 1 || imgs.length === 0;
  console.log(`${ok ? '✅' : '⚠️'} ${f}  postId=${list.postId}  正文 ${String(p.content ?? '').length} 字  images=${imgs.length}  线上图=${live.join(', ') || '(无)'}`);
  console.log(`     ${p.title}\n     ${list.postUrl}`);
}
```

> 判读：`✅` + `线上图=200/xxxxxB` 即真实可读；出现 `❌` 说明帖子被删或接口异常。
